# Codebase Rules

## Production Codebase Only
- All code modifications must strictly be made in the root directory:
  - `app/`
  - `components/`
  - `lib/`
  - `public/`
  - Root config files (`package.json`, `tailwind.config.js`, `next.config.js`, etc.)
- **DO NOT** make changes in the duplicate subfolder `invitehub/`.
